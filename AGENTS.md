# UniversityDecisionHub implementation documentation

After every implementation, fix, refactor or migration change in this repository, use the university-implementation-log skill to update `Doc/Implementation_Log.docx` before the final response. Read the project copy at `Doc/Skills/university-implementation-log/SKILL.md` if the installed skill is unavailable.

Preserve user edits and existing entries. Record actual changes, affected files, validation evidence, migration/application status and remaining integration work. Documentation updates are authorized by the user's standing request; they do not authorize additional features, database application, publication or teammate messages. Explanation-only turns do not require a new implementation entry.

## Test result documentation

Whenever the user supplies UniversityDecisionHub test results, use `university-test-log` to update `Doc/Backend_Test_Log.docx`. If unavailable in the skill catalog, read `Doc/Skills/university-test-log/SKILL.md`. Preserve existing tests; distinguish user-reported evidence from assistant execution. A command alone is not evidence of a passing run. Test recording does not authorize implementation fixes or database changes.
